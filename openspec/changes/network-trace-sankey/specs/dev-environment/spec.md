## ADDED Requirements

### Requirement: A third typed fixture for the network trace

`src/shared/fixtures/showcaseTrace.ts` SHALL export `SHOWCASE_TRACE`, annotated with `WireGraph`, as the only trace body read by demo mode, Vitest tests, Playwright specs and the fixture coverage test. It is the response shape of `GET endpoints.trace`: the same envelope as the other fixtures, `network-flow` edges carrying `metrics.delta_bps`, exactly one switch carrying `investigation` (`direction: "in"`), and it MUST exercise every drawing the network Sankey has: a `host` leaf with `clients` (at least two clients of one owner on one port and a mixed port, so both a metered ribbon and an ownership line appear), a Kubernetes branch of `node` → `pod` with `parent` chains through `application` and `namespace` groups plus one pod with only `labels.namespace`, a `pod-node` placement edge (so the `Node` layout has a wrapper), a pair of nodes sharing `labels.tier` with an edge between them (a lateral ribbon), one backward edge, a hop with an explicit `other_out_bps`, and at least one node with `status`. Switch ids SHOULD overlap `SHOWCASE_GRAPH`'s switches so that Locate from the demo Sankey finds its target on `/network/graph`. Per-hop conservation with the balance rule of `network-trace` MUST hold on the fixture with the fixture's explicit residuals.

`src/shared/fixtures/showcaseTrace.test.ts` SHALL assert that `normalizeGraph(SHOWCASE_TRACE)` yields an empty `errors` array, that every edge endpoint and `parent` references a fixture node, that exactly one node carries `investigation`, that `deriveTrace` succeeds in both directions with at least one lateral, one backward, one metered owner ribbon, one ownership line and one derived namespace card, and that together with the other two fixtures every key of `ICON_SVG_BY_KIND` and `EDGE_STYLE_BY_TYPE` (now including `host` and `network-flow`) is covered.

#### Scenario: The trace fixture covers the network drawings

- **WHEN** `showcaseTrace.test.ts` runs
- **THEN** it passes, naming the lateral, backward, owner and derived cases it found; removing the backward edge from the fixture makes it fail naming `backward`

#### Scenario: Demo mode renders the fixture on the Network views

- **WHEN** `demoMode` is `true` and the user opens `/network/sankey`, then clicks the Graph view link
- **THEN** the Sankey draws the fixture with the anchor card, a clients table, an owner card and a namespace card without any request, and the Graph view draws the same elements with `host` glyphs and `network-flow` edges, still with no request

### Requirement: `public/demo/trace.json` is generated and drift-checked

`public/demo/trace.json` SHALL be the complete `GET endpoints.trace` response body serialized from `SHOWCASE_TRACE`, generated by `npm run fixture:build` as its third target (same `JSON.stringify(…, null, 2)` plus trailing newline, untouched when identical) and never hand-edited; `npm run fixture:check` MUST fail when it drifts, naming the remedy; the file MUST be listed in `.prettierignore`; `npm run build` MUST emit `dist/demo/trace.json` beside the other two. Its two roles are the same as the others': the example payload backend developers compare against, and the URL a `config.json` can point `endpoints.trace` at (`/demo/trace.json`) to walk the real fetch path without a backend — which is how `tests/network-trace.spec.ts` exercises the Network category.

#### Scenario: Build output includes the third payload

- **WHEN** `npm run build` runs
- **THEN** `dist/demo/graph.json`, `dist/demo/storage-graph.json` and `dist/demo/trace.json` all exist

#### Scenario: A stale trace payload fails the check

- **WHEN** `SHOWCASE_TRACE` is edited and `public/demo/trace.json` is not regenerated
- **THEN** `npm run fixture:check` exits non-zero naming `npm run fixture:build`, and `pre-push` blocks the push

#### Scenario: The e2e spec walks the fetch path

- **WHEN** `tests/network-trace.spec.ts` serves a `config.json` with `demoMode: false` and `endpoints.trace: "/demo/trace.json"`, opens `/network/sankey?hostname=sw-tor-1&from=now-1h&to=now` and activates Query
- **THEN** exactly one request to `/demo/trace.json` is observed carrying the seven parameters, and `trace-svg` renders the same elements demo mode draws
